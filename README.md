# TpF3 Mod Downloader

Консольная утилита для Windows. Она скачивает моды для **Transport Fever 3** с [mod.io](https://mod.io) по ссылке на страницу мода, проверяет архив, распаковывает его в отдельную папку и при необходимости докачивает зависимости.

> **Статус:** версия 1.0.х, первый релиз. Все основные задачи были закрыты. Работает с одним модом за запуск. Все ещё могут быть проблемы и есть что доработать.

Быстрый старт: скачай архив, распакуй его и запусти `tf3_downloader.bat`. Подробности в разделе [Запуск](#запуск).

## Что умеет

- скачивает ZIP-архив мода по ссылке со страницы мода на mod.io;
- проверяет архив по контрольной сумме MD5, если mod.io её передал;
- распаковывает мод в папку-буфер с понятным названием (название берётся с mod.io или вводится вручную);
- при желании докачивает зависимости мода (до 25 штук);
- повторяет скачивание при сетевых сбоях и при несовпадении MD5;
- не скачивает заново ZIP, который уже лежит в «Загрузках» и совпадает по MD5;
- проверяет свободное место до скачивания и до распаковки;
- предупреждает, если у мода нет файла для Windows;
- показывает ошибки CRC внутри архива и спрашивает, продолжать ли распаковку;
- спрашивает подтверждение перед заменой уже существующей папки мода;
- настраивается через `config.ini`, без правки кода.

## Требования

- Windows
- Python 3.11 или новее ([python.org](https://www.python.org/downloads/)). При установке отметь «Add Python to PATH».
- пакет `requests`. Если его нет, `.bat`-файл предложит установить.
- личный API-ключ mod.io (см. ниже).

## Ключ mod.io

1. Войди в свой аккаунт на [mod.io](https://mod.io).
2. Открой страницу доступа к API: <https://mod.io/me/access>.
3. Запроси ключ и после выдачи скопируй его.

> Ключ личный. Никому его не показывай и нигде не публикуй. Если он попал в чужие руки или утёк, на странице доступа к API нажми **Regenerate API key**, чтобы получить новый.

Дальше есть два варианта.

- **Постоянно:** В обычной командной строке (CMD) выполни `setx MODIO_API_KEY "твой_ключ"`, затем открой новое окно консоли. Можно и через настройки Windows («переменные среды пользователя»). Скрипт будет брать ключ из переменной.
  - Не вводи эту команду в PowerShell: он сохраняет введённые команды, включая ключ, в файл истории.
  - Ключ хранится в профиле пользователя открытым текстом. Учитывай это.
- **Вручную:** Если переменной нет, скрипт попросит вставить ключ. При вводе он не отображается, так и должно быть: вставь его и нажми Enter. Скрипт сразу проверит ключ и даст до трёх попыток.

## Запуск

1. Скачай новый архив `TpF3_Mod_Downloader` со страницы [Releases](../../releases) > Assets.
2. Обязательно распакуй архив, можно в любую папку. В ином случае он работать не будет.
3. Запусти `tf3_downloader.bat` двойным щелчком. Можно передать ссылку параметром:

   ```
   tf3_downloader.bat https://mod.io/g/transportfever3/m/название-мода
   ```

4. Выбери режим:
   - `1` — один файл без зависимостей;
   - `2` — один файл с зависимостями;
   - `3` — несколько файлов (**пока не реализовано**).
5. Выбери, как назвать папку мода: автоматически (название с mod.io) или вручную.
6. Если переменная `MODIO_API_KEY` не задана, на этом шаге скрипт попросит ввести ключ.
7. Вставь ссылку на мод и следуй подсказкам.

Ссылка должна быть вида `https://mod.io/g/transportfever3/m/название-мода`. Ссылки на другие игры скрипт отклоняет.

## Настройка через config.ini

Все настройки лежат в файле `config.ini` рядом со скриптом. Его можно открыть в любом текстовом редакторе.

```ini
[paths]
extract_dir = C:\Games\Буфер TpF3
downloads_dir =

[behavior]
keep_zip = да
crc_policy = спрашивать
```

- `extract_dir` — папка, куда распаковываются моды. Если оставить пустым, моды только скачиваются.
- `downloads_dir` — папка для ZIP-архивов. Если оставить пустым или указанной папки нет, архивы сохраняются в «Загрузки».
- `keep_zip` — оставлять ли ZIP после распаковки: `да` или `нет`.
- `crc_policy` — что делать при ошибках CRC: `спрашивать` или `остановить` (в последнем случае распаковка не выполняется).

Что ещё нужно знать:

- Значения можно писать как на русском, так и на английском.
    - Регистр не важен: `да` / `yes` / `true`, `нет` / `no` / `false`, `спрашивать` / `ask`, `остановить` / `stop`.
- Комментарий начинается с `#` или `;`. Его можно написать отдельной строкой или в конце строки после пробела.
    - Пример: `extract_dir = C:\Mods  # моя папка`.
- Если значение не распознано, скрипт предупредит и возьмёт значение по умолчанию.
- Если `config.ini` нет или он не читается, скрипт выводит замечание и работает на значениях по умолчанию.

> Пожалуйста, не указывай в `extract_dir` папку модов самой игры. Как минимум это может навредить игре. Скрипт распаковывает мод в буфер, а переносить ли его в папку игры, ты решаешь сам.

## Файлы на диске и обновление

1. Скрипт читает `config.ini`, но никогда его не меняет и не создает новый.
2. Он создаёт папки в буфере и сохраняет ZIP в «Загрузки» или в папку из `downloads_dir`.
3. Если папка мода уже есть, скрипт спрашивает подтверждение перед её заменой. Старая версия может остаться в буфере с пометкой `.old`.
4. Если ZIP с таким именем уже есть, но не совпадает по MD5 или MD5 не проверялся, скрипт спрашивает: перезаписать, сохранить рядом с суффиксом `_1`, `_2`, `_3` или отменить.
5. После аварийно-прерванной распаковки в буфере могут остаться временные папки `tmp...`. При следующем запуске скрипт удалит их сам и сообщит об этом.
6. Установка `requests` через `.bat` выполняется отдельно и только с твоего согласия.

**Обновление:** 
- В архиве новых версий лежит `config.ini` с настройками по умолчанию. Если распаковать обновление поверх старой папки, твои настройки будут затёрты.
- Файлы `tf3_downloader.py` и `tf3_downloader.bat` заменяются без опасений.

**Переход с 0.9.x.** Раньше путь к буферу задавался в коде. Теперь он задаётся в `config.ini`.

## Сообщения и что делать

| Сообщение | Что значит | Что делать |
|---|---|---|
| «API key не найден» | Ключа нет ни в переменной, ни во вводе | Задай `MODIO_API_KEY` или введи ключ при запуске |
| «mod.io не принял ключ» | Ключ неверный или скопирован не полностью | Проверь, что ключ состоит из 32 символов, без пробелов и кавычек |
| «Контрольная сумма MD5 не совпала» | Файл повредился при загрузке или обновился на mod.io | Скрипт скачает его ещё раз. Если снова не совпало, подожди и запусти позже |
| «Внимание! Контрольные суммы в архиве не сходятся» | В одном/нескольких файлах архива не совпадает CRC, но данные распаковываются | Выбери «да», чтобы распаковать. После переноса в игру проверь мод |
| «Распаковка остановлена: в архиве есть ошибки CRC» | В `config.ini` стоит `crc_policy = остановить` | Чтобы решать самому, поставь `crc_policy = спрашивать` |
| «Недостаточно места» | Не хватает места для скачивания или распаковки | Освободи место, к примеру можно удалить старые ZIP в «Загрузках», и запусти снова |
| «Замечания по config.ini» | Настройка не распознана или файл не читается | Это предупреждение, не сбой. Проверь написание настроек |
| «Файл для Windows не найден» | У мода нет файла для ПК | Мод, скорее всего, не заработает. Скрипт спросит, скачивать ли текущий найденный файл |
| «Не удалось распаковать» | Архив повреждён внутри | Проверь архив в 7-Zip. Если он тоже ругается, напиши автору мода. ZIP останется в «Загрузках» |

## Известные ограничения

- Только Windows и только Transport Fever 3.
- Режим «несколько файлов» пока не реализован.
- Зависимостей не более 25. Большие деревья зависимостей не поддерживаются.
- Скачивается только то, что доступно через публичное API mod.io.
- Интерфейс консольный и только на русском.

## О программе

Утилита использует API [mod.io](https://mod.io). Это неофициальный клиент, он не связан с mod.io и разработчиками Transport Fever 3.

- Ключ личный. Ни в коем случае не передавай его другим и нигде не публикуй.
- Использование API и контента mod.io регулируется [условиями использования](https://mod.io/terms) и [условиями API](https://mod.io/apiterms). Соблюдай их.
- Моды принадлежат своим авторам. Утилита предназначена для личной установки, не выкладывай чужие моды в других местах без разрешения авторов.

Программа распространяется «как есть», без каких-либо гарантий (см. лицензию). Автор не отвечает за возможные потери данных или проблемы с модами, поэтому делай копии важного.

Если нашёл ошибку, создай [issue](../../issues) и приложи текст из консоли. Ключ программа маскирует, но перед отправкой всё равно лучше перепроверить.
