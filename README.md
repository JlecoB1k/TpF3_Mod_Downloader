# TpF3 Mod Downloader

Консольная утилита для Windows, которая скачивает моды для **Transport Fever 3** с [mod.io](https://mod.io) по ссылке на страницу мода, проверяет файл, распаковывает его в отдельную папку и при необходимости докачивает зависимости.

> **Статус:** бета-версия (`0.9.x`). Основная часть работает, но всё ещё есть то, что нужно и можно сделать.

## Что умеет

- скачивает ZIP-архив мода по ссылке со страницы мода на mod.io;
- проверяет целостность файла по контрольной сумме (MD5);
- распаковывает мод в папку-«буфер» с понятным названием (название берётся с mod.io или вводится вручную);
- при желании докачивает зависимости мода (до 25 штук);
- повторяет попытку при сетевых сбоях и не скачивает заново уже имеющийся целый файл;
- спрашивает подтверждение перед заменой уже существующей папки мода;
- предупреждает о слишком длинных путях, которые могут не понравиться Windows.

## Требования

- Windows
- Python 3.11 или новее ([python.org](https://www.python.org/downloads/)), при установке отметь «Add Python to PATH»
- пакет `requests` (если его нет, `.bat`-файл предложит установить)
- **личный API-ключ mod.io** (см. ниже)

## Как получить API-ключ mod.io

1. Войди в свой аккаунт на [mod.io](https://mod.io).
2. Открой раздел доступа к API в настройках аккаунта (на момент написания: <https://mod.io/me/access>).
3. Запроси ключ и после выдачи скопируй его.

> Ключ личный. Ни в коем случае никому его не показывай и нигде не публикуй. Если он всё же попал в чужие руки или утёк в сеть — перегенерируй его в настройках.

Дальше есть два варианта:

- **Постоянно:** в CMD выполни `setx MODIO_API_KEY "твой_ключ"`, затем открой новое окно консоли. Либо задай переменную через настройки Windows («переменные среды пользователя»). Скрипт будет брать ключ из переменной окружения.
  - Не вводи эту команду в PowerShell: он сохраняет введённые команды, включая ключ, в файл истории.
  - Ключ хранится в профиле пользователя в открытом виде, учитывай это.
- **Каждый раз вручную:** если переменной нет, скрипт попросит вставить ключ. При вводе он не отображается, это нормально: вставь его и нажми Enter. Сразу после ввода скрипт проверяет ключ и даёт до трёх попыток, если mod.io его не принимает.

## Запуск

1. Скачай новый архив `TpF3_Mod_Downloader` с [Releases](../../releases)
2. Обязательно распакуй его, можно в любую папку. Без этого он работать не будет.
3. Найди `tf3_downloader.bat` и запусти его двойным щелчком. Также можно передать ссылку параметром:

   ```
   tf3_downloader.bat https://mod.io/g/transportfever3/m/название-мода
   ```
4. Выбери режим:
   - `1` — один файл без зависимостей;
   - `2` — один файл с зависимостями;
   - `3` — несколько файлов (**пока не реализовано**).
5. Выбери, как назвать папку мода: автоматически (название с mod.io) или вручную.
6. Если переменная `MODIO_API_KEY` не задана, на этом этапе скрипт попросит ввести ключ.
7. Вставь ссылку на мод и следуй подсказкам.

Ссылка должна быть вида `https://mod.io/g/transportfever3/m/название-мода`. Ссылки на другие игры скрипт отклоняет.

## Куда и что сохраняется

- **ZIP-архивы** сохраняются в папку «Загрузки» (`Downloads`/`Загрузки`) в профиле пользователя. По умолчанию архивы остаются после распаковки.
- **Распакованные моды** идут в папку-буфер. По умолчанию это `C:\Games\Буфер TpF3`.

Чтобы изменить путь, открой `tf3_downloader.py` в любом текстовом редакторе, найди блок «Настройки распаковки» и измени его под себя:

```python
EXTRACT_DIR = Path(r"C:\Games\Буфер TpF3")
```

Там же настройка `KEEP_ZIP`: `True`: оставлять архивы, `False`: удалять.

Из буфера моды можно вручную перенести в папку модов игры.

## Что скрипт делает с файлами на диске

Это стоит знать заранее:

- он **создаёт папки** в буфере и **записывает файлы** в «Загрузки»;
- если папка с таким названием уже есть, он **спрашивает подтверждение** перед заменой; старая версия может остаться рядом с пометкой `.old`;
- после аварийного завершения в буфере могут остаться временные папки `tmp...`; при следующем запуске скрипт на них укажет, а удалять их или нет, решаешь ты;
- в ходе работы файлы записываются только в эти две папки (установка `requests` через `.bat` делается отдельно и только с твоего согласия).

## Известные ограничения

- Только Windows (путь и `.bat`-запуск рассчитаны на неё).
- Только Transport Fever 3.
- Режим «несколько файлов» пока не готов.
- Зависимости: максимум 25 штук, большие деревья не поддерживаются.
- Скрипт скачивает только то, что доступно через публичное API mod.io.
- Интерфейс только консольный и только на русском.

## Если что-то пошло не так

- **«API key не найден»:** задай переменную `MODIO_API_KEY` или вставь ключ при запуске.
- **«mod.io не принял ключ»:** проверь, что ключ скопирован целиком (32 символа), без пробелов и кавычек. Если он задан через `MODIO_API_KEY`, исправь значение и открой новое окно консоли.
- **«Python 3.11+ not found»:** установи Python 3.11 или новее и добавь его в PATH.
- **Ошибки с длиной пути:** сократи путь к буферу или перенеси его ближе к корню диска.
- **Не получилось скачать зависимость:** скрипт сообщит, какая именно; скачай её вручную со страницы мода.

Если нашёл ошибку, создай [issue](../../issues) и приложи текст из консоли (скрипт маскирует ключ, но перед публикацией всё равно стоит перепроверить).

## О программе

Утилита использует API [mod.io](https://mod.io).
Это неофициальный клиент, он не связан с mod.io и разработчиками Transport Fever 3.

- Для работы нужен исключительно личный API-ключ, который выдаёт mod.io в твоём аккаунте.
  Ни при каких обстоятельствах не передавай его другим и нигде не публикуй.
- Использование API и контента mod.io регулируется [условиями использования](https://mod.io/terms)
  и [условиями API](https://mod.io/apiterms). Соблюдай их.
- Моды и все права на них принадлежат своим авторам. Утилита предназначена для личной установки,
  не выкладывай чужие моды в других местах без разрешения авторов.

Значительная часть кода была написана с помощью ИИ-ассистента.
Идеи, постановка задач, принятие решений, тестирование и проверка работы — на авторе проекта.

Программа распространяется **«как есть», без каких-либо гарантий** (см. лицензию). Автор не отвечает за возможные потери данных или проблемы с модами, поэтому рекомендуется делать копии важного.
